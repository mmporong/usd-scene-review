# 한국어 사용 안내

두 로컬 USD revision을 의존 파일까지 포함한 snapshot으로 고정하고, 같은 시간·variant·load 조건에서 의미를 비교합니다. 원본 수정·자동 병합·충돌 확정 판정은 제공하지 않습니다. 근거가 부족하면 `unknown`으로 표시합니다.

현재 Windows 대상은 Isaac Sim 4.5 / Kit 106.5 / Python 3.10 / OpenUSD 22.11입니다. 이 환경에서 CPU 검사와 실제 Kit의 합성 정적 장면 A/B 부착·렌더링·선택·프레이밍·반복 전환·닫기/다시 열기를 검증했습니다. 기본 장면 내용·dirty 상태·선택·타임라인과 snapshot 해시 보존도 확인했습니다. 전체 Isaac 앱, 실제 사용자 장면, 대규모 장면이나 다른 버전의 통과를 뜻하지는 않습니다.

resolver 이름을 보고 허용하지 않습니다. 실제 파일 해석 결과와 USD가 사용한 레이어가 고정된 로컬 파일 목록에 속하는지 확인합니다. 경로 이탈·재매핑·원격 경로·확인할 수 없는 해석은 `unknown`입니다. 애니메이션 장면은 지정 시간의 의미 비교만 제공하며 viewport 부착은 거부합니다.

명령과 설치 방법은 [README](../README.md), 검증 범위와 남은 한계는 [검증 기록](validation.md)에 있습니다. 종료 코드 0은 충돌이 없다는 보증이 아닙니다. 검증에는 새 합성 fixture만 사용했고 사용자 장면이나 시스템 설정을 변경하지 않았습니다.
